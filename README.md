# AI Agent 小说写作系统

由多个 AI Agent 协作完成长篇小说创作的系统。后端 FastAPI + Anthropic Claude，前端 React。

> 架构设计见 [docs/architecture.md](docs/architecture.md)。已落地**阶段 1–5**，并推进阶段 6/7 子项：多 Agent 协作（大纲/角色/写作/审校/修订）、三层记忆（摘要/关键词 RAG/实体状态）、审改闭环、去 AI 味、参考文本拆书与文风指纹、伏笔/支线追踪、长篇真相文件、章节就地编辑、整书阅读、进度看板与 Markdown / EPUB 导出。

## 目录结构

```
backend/    FastAPI + Claude 流式生成 API
frontend/   Vite + React 流式写作界面
docs/       架构设计文档
```

## 快速开始

### 1. 后端

```powershell
cd backend
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt

# 配置 API Key
Copy-Item .env.example .env
# 编辑 .env：填入 ANTHROPIC_API_KEY；如需走本地/自定义代理，设置 ANTHROPIC_BASE_URL
# 开发环境也支持直接读取仓库根目录 .claude/settings.json 的 Agent Maestro 配置

uvicorn app.main:app --reload --port 8000
```

后端启动后：
- 健康检查：http://localhost:8000/health
- 接口文档：http://localhost:8000/docs

### 2. 前端

```powershell
cd frontend
npm install
npm run dev
```

打开 http://localhost:5173 ，填写设定与本章大纲，点击「生成本章」即可看到流式生成的小说正文。

> 前端通过 Vite 代理把 `/api` 请求转发到 `http://localhost:8000`，无需额外配置跨域。

## 已实现（阶段 1–5 + 阶段 6/7 部分）

- ✅ FastAPI 服务 + CORS，Claude 流式生成封装（`anthropic` SDK）
- ✅ 多 Agent：大纲 / 角色 / 写作 / 审校 / 修订 Agent（tool-use 结构化输出）
- ✅ 数据库持久化项目 / 卷 / 章节 / 设定 / 审校报告
- ✅ 三层记忆：分层摘要、关键词 RAG、实体状态追踪；手动编辑/修订后会刷新章节记忆
- ✅ 审校闭环：生成→审校→自动修订，一致性报告与去 AI 味 / AIGC 检测维度
- ✅ 设定管理闭环：设定增删改、检索片段同步、写作/审校/修订上下文注入
- ✅ 可配置/追加/补齐大纲：项目工作台可填写新增卷数与目标章数/卷，二次生成会承接已有大纲并继续追加；补齐旧卷不会删除或重排已有章节
- ✅ 伏笔/支线追踪：维护伏笔、支线、资源线、情感线及状态，同步检索片段并注入写作/审校/修订上下文；成稿章节可生成状态建议并手动应用；总览页提供跨章追踪仪表盘
- ✅ 长篇真相文件：维护硬约束、资源账本、关系弧、隐藏真相和时间锚点；同步 `truth_file` 检索片段，写大纲、写章节、审校、修订和上下文预览都会纳入；总览页可一键检查真相文件与设定、角色、正文卷章之间的明确矛盾，并给出证据、来源跳转、修正建议和维护清单；状态类维护建议支持单条/批量应用，并记录最近处理历史；Markdown / EPUB 导出会带上真相文件资料
- ✅ 参考文本拆书与文风指纹：项目总览可导入 `.txt` / `.md` 文本文件或直接粘贴参考片段，提炼文风指纹、设定、角色、伏笔/支线，并生成本地统计指纹（句长、段落、对白占比、标点节奏、高频词/重复风险）和文风样例片段库；分析结果会标出重复/可能冲突项，并可自动写入非冲突资料；也可按章节导入为“参考资料”分组，原文不改写、不计入正文进度/导出，同时生成摘要、检索片段和实体状态时间线；成稿正文或参考章节可设为续写起点，正式章节详情可预览生成时会注入的上下文，并显示检索命中原因、分数和来源跳转
- ✅ 全局模型选择：全局默认来自 `.env` / `.claude/settings.json`，界面右上角可选择本次工作使用的模型；项目内角色、大纲、写作、审校、修订、线索建议和拆书分析统一使用该选择
- ✅ React 三栏式项目工作台 + 流式写作界面 + 章节就地编辑
- ✅ 项目总览：总字数、章节进度、审校问题、AI 味均分、整书大纲与整书阅读视图；整书阅读支持按卷、成稿状态、审校风险、AI 味和关键词筛选，可显示未成稿大纲并批量重审当前结果
- ✅ Markdown / EPUB 导出：项目动作区可下载 `.md` / `.epub`，并可选择只导正文，或附带作品资料、未成稿大纲、审校报告和参考资料
